## Project Description
This is a cafe website developed using HTML, CSS and JavaScript. It has a simple beige and brown theme and provides information about the cafe, its menu, gallery and contact details.

## Website Pages
1. Home – Introduction to the cafe.
2. Menu – Displays available coffee drinks and prices.
3. Gallery – Displays coffee pictures.
4. Contact – Provides cafe contact information.
